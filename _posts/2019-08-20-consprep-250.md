今年内を目標にコンソーシアムを設立準備していますが、現在のところの参加表明状況をお届けします。






参加表明機関は貴機構を含み8機関、個別参加しているが現在意向を伺っているのは5機関、コンソーシアムができれば新規に参加と検討している機関は3機関です。



ちなみに、コンソーシアムの会員数に応じて会費設定が変わります。以下はコンソーシアム事務手数料を10％とした場合の金額です。



|  |  |
| --- | --- |
| 参加機関数範囲 | ORCID参加費($) |
| 5~9 | 6,600 |
| 10~19 | 5,500 |
| 20~34 | 4,400 |
| 35~60 | 3,850 |
| 61~ | 3,300 |
